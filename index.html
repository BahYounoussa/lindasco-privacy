Politique de Confidentialité

1. Introduction

Guinée Digital Pub (GDP), développeur de l'application Lindasco, s'engage à protéger la vie privée des utilisateurs. Cette politique décrit comment nous collectons, utilisons et protégeons vos données personnelles.

En utilisant Lindasco, vous acceptez les pratiques décrites dans cette politique.

2. Données collectées

Nous collectons uniquement les données nécessaires au bon fonctionnement de l'application :

  • Informations de profil : nom, prénom, numéro de téléphone
  • Données scolaires : notes, absences, présences, emplois du temps
  • Données de paiement : montants, moyens de paiement (aucune donnée bancaire sensible)
  • Token FCM : pour l'envoi de notifications push

3. Utilisation des données

Les données collectées sont utilisées exclusivement pour :

  • Permettre la connexion et l'authentification des utilisateurs
  • Afficher les informations scolaires (notes, présences, bulletins)
  • Envoyer des notifications aux parents et élèves
  • Générer des bulletins PDF
  • Suivre les paiements scolaires

4. Partage des données

Vos données ne sont jamais vendues à des tiers. Elles sont partagées uniquement avec :

  • Supabase : hébergement sécurisé de la base de données
  • Firebase (Google) : notifications push uniquement
  • L'établissement scolaire auquel vous êtes rattaché

5. Sécurité

Nous prenons la sécurité de vos données très au sérieux :

  • Les mots de passe sont chiffrés avec l'algorithme SHA-256
  • Les données sont isolées par établissement scolaire
  • Les communications utilisent le protocole HTTPS
  • Aucun mot de passe n'est stocké en clair

6. Données des mineurs

Lindasco est une application scolaire qui peut traiter des données d'élèves mineurs. Ces données sont gérées exclusivement par les établissements scolaires partenaires et ne sont utilisées qu'à des fins éducatives.

Les parents ont accès aux données de leurs enfants via l'espace parent de l'application.

7. Vos droits

Conformément aux réglementations en vigueur, vous disposez des droits suivants :

  • Droit d'accès à vos données personnelles
  • Droit de modification de vos informations
  • Droit à la suppression de votre compte
  • Droit d'opposition au traitement de vos données

Pour exercer ces droits, contactez-nous à l'adresse ci-dessous.

8. Conservation des données

Les données sont conservées tant que l'établissement scolaire est actif sur la plateforme Lindasco. En cas de résiliation, les données sont supprimées dans un délai de 30 jours.
